# Landfill profiles

This directory stores reviewed site metadata for the local ZoomInSAR dashboard.
Keep one JSON file per landfill using `profile_template.json` as the starting
point. The dashboard may display only information recorded here, so every
operational-status, ownership, regulatory, or deformation statement must have
an authoritative source URL and an access date.

Recommended sources are the relevant municipal or county solid-waste agency,
state environmental regulator, landfill permit or monitoring documents, and
peer-reviewed or agency technical reports. Do not infer facility status from
satellite imagery or deformation alone.

`environmental_products.json` records candidate open thermal and soil-moisture
products. It is a data catalogue, not a statement that any product has been
downloaded, quality controlled, or is suitable for site-scale interpretation.
